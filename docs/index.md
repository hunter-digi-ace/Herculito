# Documentación, Herculito

Repositorio del robot Herculito, microsumo de 5×5×5 cm de 2019. El chasis es de
Mario V.C. y la placa, de Esdrufao.

## Índice

1. [Hardware y pinout](01-hardware.md), componentes, alimentación y conexionado
2. [PCB](02-pcb.md), la placa de Esdrufao y su esquema
3. [Sensores](03-sensores.md), los 6 TCRT5000 y su montaje
4. [Software](04-software.md), el sketch de siguelineas

## Resumen

| | |
|---|---|
| Categoría | Microsumo (máx. 5×5×5 cm; < 100 g) |
| MCU | ATmega328P (Arduino Mini) |
| Driver de motores | L293D |
| Sensores | 6× TCRT5000 (3 suelo + 3 enemigo) |
| Tracción | 2× servo modificado (motor + reductora) |
| Alimentación | 7.2 V (`J13`) con interruptor |
| Chasis | diseño de Mario V.C. (impresión 3D) |
| Placa | de Esdrufao |
| Año | 2019 |

## Notas

- El nombre lo eligió Esdrufao: *"por lo robusto que se ve, lo llamaría
  Herculito"*.
- La placa es un diseño de microsumo de Esdrufao.
